# Healthcare Density Analysis using Kernel Density Estimation

## 📌 Project Overview

This project demonstrates the application of **Kernel Density Estimation (KDE)** in ArcGIS Pro to analyze the spatial distribution of healthcare facilities across Telangana, India.

Kernel Density Analysis transforms individual hospital locations into a continuous density surface, allowing the identification of areas with high and low concentrations of healthcare facilities.

The project demonstrates how GIS can support healthcare planning, accessibility assessment, and spatial decision-making.

---

## 🎯 Objectives

- Analyze the spatial distribution of healthcare facilities.
- Identify healthcare concentration hotspots.
- Visualize healthcare density using Kernel Density Estimation.
- Produce a professional cartographic output for spatial analysis.

## 🔄 Workflow

1. Clip hospital locations to Telangana boundary.
2. Project the dataset into a projected coordinate system.
3. Generate a Kernel Density raster.
4. Clip the raster using Telangana boundary.
5. Apply professional cartographic symbology.
6. Export the final map layout.

---

## 📊 Results

Kernel Density Analysis revealed significant healthcare concentration around major urban regions, particularly Hyderabad and other district headquarters.

The analysis highlights variations in healthcare facility distribution and demonstrates how Kernel Density Estimation can support healthcare accessibility assessment and regional planning.
