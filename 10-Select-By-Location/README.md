# Select By Location Analysis – Hyderabad District

## Overview
This project demonstrates the **Select By Location** geoprocessing tool in ArcGIS Pro. The analysis identifies cities that are spatially located within the Hyderabad district boundary and exports both the selected district and selected cities as independent feature classes.

## Objective
- Select Hyderabad district from Telangana districts.
- Identify all cities located within Hyderabad district.
- Export selected polygon and point features into new shapefiles.
- Produce a professional map layout for visualization.

## Software
- ArcGIS Pro

## Data Used

- Telangana Cities
- Telangana Boundary
- ArcGIS Online World Topographic Basemap

## Tools Used
