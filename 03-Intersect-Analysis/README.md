# Intersect Analysis

## Overview

This project demonstrates the Intersect geoprocessing tool in ArcGIS Pro.

The analysis identifies the common spatial area shared between a 50 km buffer around Hyderabad and the Telangana district boundaries. The output retains only the overlapping portions of the districts that fall within the buffer zone.

---

## Objective

- Demonstrate the Intersect geoprocessing tool.
- Identify the overlapping area between Hyderabad's 50 km buffer and Telangana districts.
- Understand spatial overlay analysis in GIS.

---

## Input Data

- Hyderabad (Point Feature)
- Hyderabad 50 km Buffer (Polygon)
- Telangana District Boundaries (Polygon)
- India State Boundary (Reference Layer)

---

## Tool Used

ArcGIS Pro → Analysis → Overlay → Intersect

---

## Output

The resulting layer contains only the portions of Telangana districts that intersect with the 50 km buffer around Hyderabad.
