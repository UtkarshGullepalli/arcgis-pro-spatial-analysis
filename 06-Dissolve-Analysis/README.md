# Dissolve Analysis

## Overview

This project demonstrates the Dissolve geoprocessing tool in ArcGIS Pro.

The Dissolve tool merges adjacent features that share a common attribute into a single feature. In this project, India district boundaries were dissolved using the **STATE** field, resulting in a state-level administrative boundary layer.

---

## Objective

- Demonstrate the Dissolve geoprocessing tool.
- Merge district boundaries into state boundaries.
- Understand feature generalization based on a common attribute.

---

## Input Data

- India District Boundaries

---

## Dissolve Field

- STATE

---

## Tool Used

ArcGIS Pro → Analysis → Data Management → Dissolve

---

## Output

The output contains state-level polygons created by merging district boundaries that share the same state name.
