# Merge Analysis

## Overview

This project demonstrates the Merge geoprocessing tool in ArcGIS Pro.

The Merge tool combines multiple feature classes of the same geometry type into a single output feature class while preserving the original geometries and attribute information. In this project, the Telangana Districts and Andhra Pradesh Districts datasets were merged into a single feature class for regional spatial analysis.

---

## Objective

- Demonstrate the Merge geoprocessing tool.
- Combine multiple district datasets into a single feature class.
- Preserve the geometry and attributes of all input features.

---

## Input Data

- Telangana Districts
- Andhra Pradesh Districts

---

## Tool Used

ArcGIS Pro → Data Management → Merge

---

## Output

A single feature class containing the districts of both Telangana and Andhra Pradesh while maintaining their original boundaries and attributes.
