## Objective
Remove Telangana districts from the India Districts layer using the Erase tool.

## Input Data
- India Districts
- Telangana Boundary

## Tool Used
- Erase (Analysis)

## Output
- India Districts without Telangana

## Applications
- Regional analysis
- Data preprocessing
- Spatial masking
- Administrative filtering

## Software
- ArcGIS Pro
