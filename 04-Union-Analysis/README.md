# Union Analysis

## Overview

This project demonstrates the **Union** geoprocessing tool in ArcGIS Pro. Union combines two polygon feature classes into a single output while preserving the geometry and attribute information from both input layers.

---

## Objective

To perform a Union Analysis between the India State Boundary and Telangana Boundary datasets and visualize the combined polygon output.

---

## Software Used

- ArcGIS Pro

---

## Input Layers

- India State Boundary (Polygon)
- Telangana Boundary (Polygon)

---

## Geoprocessing Tool

- Union
