# Buffer Analysis Around Hyderabad (50 km)

## Overview

This project demonstrates Buffer Analysis using ArcGIS Pro by creating a 50 km buffer around Hyderabad city. Buffer Analysis is used to identify areas within a specified distance from a geographic feature.

---

## Objective

To generate a 50 km buffer around Hyderabad and visualize its area of influence.

---

## Software Used

- ArcGIS Pro

---

## Data Used

- Hyderabad City (Point)
- India State Boundary

---

## Workflow

1. Added the Hyderabad point layer.
2. Opened the Buffer tool.
3. Set the buffer distance to 50 kilometres.
4. Generated the buffer polygon.
5. Applied symbology and transparency.
6. Designed the final layout with map elements.
