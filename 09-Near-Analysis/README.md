# Near Analysis – Nearest Police Station Analysis (Telangana)

## Project Overview

This project demonstrates proximity analysis using ArcGIS Pro's Near tool to determine the nearest police station for every city in Telangana.

The workflow calculates the nearest police station, distance, direction, and transfers police station information into the city dataset for further spatial analysis.

---

## Objective

- Find the nearest police station for every city.
- Calculate the nearest distance.
- Join police station information to city features.
- Perform attribute calculations.
- Produce a professional GIS map layout.

---

## Dataset

- Telangana Cities
- Telangana Police Stations
- Telangana Boundary

---

## Workflow

1. Import datasets
2. Execute Near Analysis
3. Generate nearest feature IDs
4. Calculate nearest distance
5. Join police station attributes
6. Verify attribute table
7. Design final layout
8. Export final map
