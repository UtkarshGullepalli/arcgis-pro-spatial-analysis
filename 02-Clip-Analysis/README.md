# Clip Analysis using ArcGIS Pro

## Overview
This project demonstrates the Clip geoprocessing tool in ArcGIS Pro by extracting Telangana districts from the India District Boundary dataset using the Telangana state boundary.

## Objective
To extract all districts within Telangana from the national district dataset.

## Software
- ArcGIS Pro

## Input Data
- India District Boundary
- Telangana Boundary

## Tool Used
- Clip (Analysis Tools)

## Output
- Telangana Districts

## Map Elements
- Title
- Legend
- North Arrow
- Scale Bar
- Basemap

## Output Files
- Telangana_Clip_Analysis.png
- Telangana_Clip_Analysis.pdf
