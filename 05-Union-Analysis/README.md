# Union Analysis

## Overview

This project demonstrates the Union geoprocessing tool in ArcGIS Pro.

Union combines two polygon feature classes into a single output while preserving the geometry and attribute information from both input layers. In this project, the India State Boundary and Telangana Boundary datasets were used to generate a combined polygon layer for spatial overlay analysis.

---

## Objective

- Demonstrate the Union geoprocessing tool.
- Combine India State Boundary and Telangana Boundary into a single output.
- Preserve the geometry and attributes of both input datasets.

---

## Input Data

- India State Boundary (Polygon)
- Telangana Boundary (Polygon)

---

## Tool Used

ArcGIS Pro → Analysis → Overlay → Union

---

## Output

The output contains all polygon areas from both input datasets while preserving their respective attributes.
