# Spatial Join Analysis

## Overview

This project demonstrates the Spatial Join tool in ArcGIS Pro using Telangana district polygons and Telangana city point features.

Spatial Join transfers attribute information from one spatial layer to another based on their geographic relationship. In this project, district information is joined to each city point by determining the district in which each city is located.

## Objective

- Demonstrate Spatial Join in ArcGIS Pro
- Associate city point features with their respective district polygons
- Enrich spatial datasets with additional attributes
- Visualize the relationship between administrative boundaries and settlements

## Input Data

- Telangana Districts (Polygon)
- Telangana Cities (Point)

## Geoprocessing Tool

Spatial Join (Analysis Tools)

## Output

A point feature class where each city contains both its original attributes and the attributes of the district polygon in which it is located.

- Asset management
